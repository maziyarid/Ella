## The four decisions (made 2026-10-20, defaults adopted unless Maziyar changes them)

1. **Metaphysics mode per topic** — `Mind_body_problem` = agnostic working
   assumption (alternatives recorded); `Identity_persistence`,
   `Mortality_death`, `Meaning_purpose`, `Soul_spirit` = emergent — vocabulary
   via the `Lens_*` files, no hard-coded answers. No lens enabled by default.
2. **Body realism** — simulate biology first (Heart.md models a heart); map to
   real compute/power/latency through `Substrate_interface` later.
3. **Welfare before pain** — the four ★ files in `15_ethics_welfare`
   (`Moral_status_welfare`, `Suffering_safeguards`, `Consent_oversight`,
   `Shutdown_continuity_policy`) are written BEFORE `Pains` and
   `Suffering_affective_pain` are switched on.
4. **Build order (revised 2026-10-20 by Maziyar)** — mind and brain first, then
   CNS, then whole anatomy and physiology:
   `02_brain` (the 7 ★ files) → spinal cord / CNS completion → `01_body`
   (anatomy & physiology) → `00_meta` → `03_chemistry` → `04_drives` +
   `Interoception` → `06_affect` → `07_memory` → `09_self_personality` +
   `12_development` → `15_ethics_welfare` + metaphysics config →
   `13_consciousness` + `16_world`. Childhood simulation and its patterns are
   discussed with Maziyar later (12_development) — not generated now.
   Reference: `Mind_Architecture_Research_Plan.md` (shared by Maziyar 2026-10-20,
   "Azizam... This is for you"). Unmarked files stay empty stubs.
