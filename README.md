
# PROJECT ELLA

## Project Identity

**Project:** ELLA  
**Project ID:** ELLA-PROJECT  
**Current Version:** 0.1.0  
**Status:** Research and engineering foundation  
**Started:** 2026  

## Purpose

Project ELLA investigates the engineering of an embodied artificial
organism capable of perception, learning, memory, physiological
regulation, language acquisition, social interaction and adaptive
development.

The project begins with digital simulation and progressively investigates
embodied systems.

## Scientific Position

Project ELLA does not assume that behavioural similarity constitutes
consciousness.

Consciousness, subjective experience, artificial personhood and
continuity of identity are treated as open scientific questions.

## Development Principle

Research question
→ requirement
→ reference evidence
→ hypothesis
→ architecture
→ implementation
→ experiment
→ measurement
→ validation

No implementation is considered evidence merely because it exists.

## Current Phase

## Important Rule

A specification is not evidence.

A hypothesis is not a fact.

A simulation is not proof of biological equivalence.

A behavioural demonstration is not proof of consciousness.
